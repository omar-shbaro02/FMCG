# Security policy

Report vulnerabilities privately to the project security owner. Do not include
client datasets, credentials, tokens, or commercial values in an issue.

Only supported releases receive security updates. Never commit `.env` files or
real FMCG data. Development defaults are not production secrets. Authentication,
authorization, upload hardening, auditing, and deployment controls are delivered
in their ordered backlog tasks and must pass Task 23 before pilot use.
